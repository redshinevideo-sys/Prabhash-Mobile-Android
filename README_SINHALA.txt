PRABHASH MOBILE & ELECTRICAL - ANDROID APP

මෙය දැනට තිබෙන GitHub Pages system එක Android app එකක් ලෙස open කරන native WebView wrapper එකකි.

App URL:
https://redshinevideo-sys.github.io/Prabhash-Mobile/

වැදගත්:
- Existing Supabase database එකට කිසිම migration එකක් හෝ වෙනස් කිරීමක් මෙම project එකෙන් සිදු නොවේ.
- Login/session එක web app එක හරහාම පවතී.
- Android Studio භාවිතයෙන් APK build කළ හැක.

Build:
1. Android Studio install කරන්න.
2. මෙම project folder එක Open කරන්න.
3. Gradle Sync අවසන් වනතුරු ඉන්න.
4. Build > Build APK(s) තෝරන්න.
5. app/build/outputs/apk/debug/app-debug.apk file එක ලැබේ.
